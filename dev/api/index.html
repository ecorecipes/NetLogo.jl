API Reference

This page includes every exported public API entry. The docs build enforces that coverage with checkdocs = :exports.

Module

NetLogo — Module
NetLogo

Headless-first, clean-room Julia implementation of the NetLogo language and runtime.

Compilation and model loading

NetLogo.tokenize — Function
tokenize(source)

Tokenize NetLogo source text into a vector of source-spanned lexical tokens.

NetLogo.parse_model — Function
parse_model(source; source_path=nothing, extension_host=Main)

Parse NetLogo source into a ModelSpec, resolving declarations, procedures, widgets, includes, and extension metadata.

Set source_path when parsing file-backed models so relative __includes paths are resolved correctly.

NetLogo.compile_model — Function
compile_model(source; source_path=nothing, extension_host=Main)
compile_model(model::ModelSpec; source_path=nothing)

Compile NetLogo source into a CompiledModel. Passing an existing ModelSpec returns it unchanged for API symmetry.

NetLogo.load_model — Function
load_model(path; extension_host=Main)

Read a .nlogo model from disk, resolve its includes relative to path, and compile it into a CompiledModel.

NetLogo.@netlogo_str — Macro
netlogo"..."

Compile NetLogo source embedded in a Julia string literal.

Runtime execution

NetLogo.create_runtime — Function
create_runtime(model; extension_host=Main, kwargs...)

Create a fresh executable runtime for a compiled model. Keyword arguments are forwarded to the world/runtime constructor, including common options such as seed, topology overrides, and world bounds.

NetLogo.call! — Function
call!(runtime, procedure_name, args...)

Invoke a NetLogo procedure by name against an existing runtime.

NetLogo.run_commands! — Function
run_commands!(runtime, command_string)

Compile and execute an arbitrary NetLogo command string (one or more statements) in the observer context. This is the command analogue of runresult.

NetLogo.runresult — Function
runresult(runtime, expr_string)

Evaluate a NetLogo reporter expression string and return the result.

NetLogo.gui_session — Function
gui_session(runtime::RuntimeState)
gui_session(model::ModelSpec; extension_host=Main, kwargs...)

Create a GUI session from an existing runtime or from a compiled model. When passed a model, keywords are forwarded to create_runtime.

NetLogo.gui_state — Function
gui_state(session::GUISession)

Return a JSON-friendly snapshot of the current GUI-visible state: widgets, ticks, plots, output buffers, and view metadata.

NetLogo.set_gui_widget! — Function
set_gui_widget!(session::GUISession, selector, value)

Update a GUI control in-place. selector can be a 1-based widget id or a widget/global name.

NetLogo.press_gui_button! — Function
press_gui_button!(session::GUISession, selector)

Execute a GUI button by 1-based widget id or button label.

NetLogo.start_web_gui — Function
start_web_gui(session::GUISession; host="127.0.0.1", port=8080)
start_web_gui(runtime::RuntimeState; host="127.0.0.1", port=8080)
start_web_gui(model::ModelSpec; host="127.0.0.1", port=8080, extension_host=Main, kwargs...)

Start a lightweight local web UI for a NetLogo runtime or model.

NetLogo.stop_web_gui! — Function
stop_web_gui!(backend::WebGUIBackend)

Stop a running local web GUI server.

NetLogo.web_gui_url — Function
web_gui_url(backend::WebGUIBackend)

Return the local URL for a running web GUI backend.

NetLogo.notebook_gui — Function
notebook_gui(backend::WebGUIBackend; width=1100, height=900, title="NetLogo.jl GUI")
notebook_gui(session::GUISession; host="127.0.0.1", port=8080, width=1100, height=900, title="NetLogo.jl GUI")
notebook_gui(runtime::RuntimeState; host="127.0.0.1", port=8080, width=1100, height=900)
notebook_gui(model::ModelSpec; host="127.0.0.1", port=8080, width=1100, height=900, extension_host=Main, kwargs...)

Create a notebook/Pluto-friendly iframe wrapper around the local web GUI.

NetLogo.pluto_gui — Function
pluto_gui(args...; kwargs...)

Alias for notebook_gui for Pluto-oriented workflows.

NetLogo.parse_turtle_shapes_text — Function
parse_turtle_shapes_text(text)

Parse the upstream turtle-shape text format into the internal shape representation used by headless rendering.

NetLogo.load_turtle_shapes! — Function
load_turtle_shapes!(runtime, text)

Parse upstream NetLogo turtle-shape text and register the resulting custom shapes into a runtime.

Extension registration

NetLogo.register_primitive! — Function
register_primitive!(registry, name, kind, syntax, evaluator)

Register a primitive implementation in a primitive registry. This is the low-level hook used by built-in and external extensions.

Source and parser types

NetLogo.SourceSpan — Type
SourceSpan

Source-location range used for parser diagnostics and error reporting.

NetLogo.Diagnostic — Type
Diagnostic

Parser or static-analysis error annotated with a SourceSpan.

NetLogo.TokenKind — Type
TokenKind

Enumeration of lexical token categories produced by tokenize.

NetLogo.Token — Type
Token

Lexical token with kind, original lexeme, parsed value, and source span.

NetLogo.BlockNode — Type
BlockNode

AST node representing a command block in parsed NetLogo source.

NetLogo.ProcedureSpec — Type
ProcedureSpec

Parsed procedure definition, including its inputs, body, and source span.

NetLogo.ModelSpec — Type
ModelSpec

Parsed model representation containing declarations, procedures, widgets, plots, and metadata.

NetLogo.CompiledModel — Type
CompiledModel

Alias for ModelSpec, retained as the compiled-model API surface.

Runtime and agent types

NetLogo.RuntimeState — Type
RuntimeState

Mutable runtime container holding the compiled model, world state, primitive registry, files, plots, and output buffers.

NetLogo.Context — Type
Context

Execution context for evaluating procedures and blocks against a specific current agent.

NetLogo.GUISession — Type
GUISession

Host-side GUI session that wraps a RuntimeState with a lock for browser or notebook interaction.

NetLogo.WebGUIBackend — Type
WebGUIBackend

Running local HTTP GUI backend for a GUISession.

NetLogo.NotebookGUI — Type
NotebookGUI

Notebook-friendly wrapper that renders an iframe pointing at a running WebGUIBackend.

NetLogo.LogoRuntimeError — Type
LogoRuntimeError

Runtime exception type raised for NetLogo execution errors.

NetLogo.Observer — Type
Observer

Observer agent value that owns the global variable map for a running model.

NetLogo.Turtle — Type
Turtle

Concrete turtle agent record used by the runtime world state.

NetLogo.Patch — Type
Patch

Concrete patch agent record used by the runtime world state.

NetLogo.Link — Type
Link

Concrete link agent record used by the runtime world state.

NetLogo.AgentSet — Type
AgentSet

Typed collection of live NetLogo agents, with optional breed and dynamic-world metadata.

Enumerations

NetLogo.AgentKind — Type
AgentKind

Enumeration of NetLogo agent categories: observer, turtle, patch, and link.

NetLogo.TopologyMode — Type
TopologyMode

Enumeration of supported 2D world topologies.

NetLogo.Torus — Constant
Torus

Topology mode that wraps on both axes.

NetLogo.VerticalCylinder — Constant
VerticalCylinder

Topology mode that wraps on the x-axis but not the y-axis.

NetLogo.HorizontalCylinder — Constant
HorizontalCylinder

Topology mode that wraps on the y-axis but not the x-axis.

NetLogo.BoxTopology — Constant
BoxTopology

Topology mode that does not wrap on either axis.
